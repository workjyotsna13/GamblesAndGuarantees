# Gambles and Guarantees

A short theoretical project on choice under uncertainty: expected utility, the certainty equivalent, Arrow Pratt risk aversion, and a simple insurance problem.

## Question

When wealth is random, how much would a decision maker pay to replace the gamble with a sure amount, and how does that payment change with curvature of utility?

## Contents

- `notes/question.md` — research question and setup
- `notes/expected-utility.md` — von Neumann Morgenstern representation
- `notes/arrow-pratt.md` — absolute and relative risk aversion
- `notes/insurance.md` — premium and coverage in a two state loss model
- `analysis/risk_premium.py` — numerical certainty equivalents for CRRA utility
